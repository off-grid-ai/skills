# Pick up any chat where it stopped

![](overview.png)

Name an old chat and your agent finds it, from any Claude Code account or Codex on your computer, reads how it ended, and tells you in two sentences. Then it carries on, or asks you the one open question.

Use it when:
- You started something in another terminal or account and want to continue here.
- A chat ran out of context and you need a fresh one that knows what happened.
- You forgot what a session last week was doing.

Try it: `/resume-any-chat pricing page` or "take over the pricing page chat".
