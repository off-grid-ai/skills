# Get an agent that pushes back with facts, not one that just agrees

![How argue-with-me works](../../assets/skills/argue-with-me.png)

Your agent stops folding when you sound sure. It checks your claim against the data, tells you which part is fact and which is a guess, and disagrees in one line before it gets on with the work.

Use it when:
- You want a second opinion, not a yes.
- You've corrected the agent and want it to keep the rest of the plan.
- A theory about a bug or a decision needs checking before anyone builds on it.
- The agent is overindexing on your last message.

Try it: "/argue-with-me I think signups dropped because of the new pricing page. Argue with me."
