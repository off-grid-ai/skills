# Take a change all the way to release-ready

![](overview.png)

Your agent finishes the work, reviews every screen and test as it goes, gets CI green, puts a screen review page in the PR and hands you one short report. It never merges or ships without your yes.

Use it when:
- A feature is mostly built and you want it finished and in a PR.
- The work spans several repos or a shared package.
- You want design, tests and device checks done in the same pass, not as follow-ups.

Try it: "Get it live: finish the new onboarding flow, get CI green and open the PR."
