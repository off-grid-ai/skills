# Ship releases you trust

Proof it works on real devices before anyone else sees it.

| Skill | What you get |
| --- | --- |
| [**get-it-live**](get-it-live) | Take a piece of work all the way to release-ready: built, tested and seen working. |
| [**test-on-real-phones**](test-on-real-phones) | Check a release on real phones and computers, with a clear bar for a good test. |
| [**tests-that-follow-the-user**](tests-that-follow-the-user) | Tests that prove the whole user journey, not just one function. |
| [**tests-that-catch-bugs**](tests-that-catch-bugs) | Tests that catch real bugs instead of passing by default. |
| [**run-on-real-devices**](run-on-real-devices) | Your agent runs and drives your app on a computer, an iPhone and an Android phone. |
| [**release-notes-people-read**](release-notes-people-read) | Release notes your users actually read, written from what changed. |
| [**ship-releases-cleanly**](ship-releases-cleanly) | Clean release branches, with screenshots on every pull request. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill get-it-live test-on-real-phones tests-that-follow-the-user tests-that-catch-bugs run-on-real-devices release-notes-people-read ship-releases-cleanly
```
