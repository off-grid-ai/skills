# Prove your game changes work, on screen

![](overview.png)

Your agent proves each change with something you can see: a render, a clip, a debug reply or a log line. A compile pass alone never counts.

Use it when:
- Your game has few or no automated tests.
- The agent says "done" and you want to see it.
- A change touches animation, combat or anything that moves.

Try it: "Prove the new dodge roll works, with a clip I can watch."
