# Show your game work: small commits, screenshots, true docs

![](overview.png)

Your agent commits and pushes in small proven steps, sends you a captioned screenshot of every new scene, and keeps the README and design doc true. Nothing goes public without your yes.

Use it when:
- You want to see each new screen as it lands.
- You are preparing a release or a store build.
- You worry about third-party assets or licences leaking into a public repo.

Try it: "Push what's done and show me screenshots of every scene you changed."
