# Playtest every scene of your game, with pictures

![](overview.png)

Your agent builds a checklist of every screen and scene, renders and checks each one, and reports pass or fail with a screenshot. It also scores how fun a real session is against the last run.

Use it when:
- You want to know what is broken across the whole game, not one scene.
- You are about to cut a build or a release.
- You changed a shared system and want to see what it touched.

Try it: "Playtest every scene and tell me what's broken, with screenshots."
