# Run a product team of agents

Your agent works like a senior team: it knows what's urgent, what good looks like, and when to ask.

| Skill | What you get |
| --- | --- |
| [**act-like-a-cto**](act-like-a-cto) | Your agent decides what's urgent, does the clear work, and asks you only the real calls. |
| [**make-it-look-great**](make-it-look-great) | A design bar every screen and flow has to clear. |
| [**change-code-safely**](change-code-safely) | Code that's changed, checked and committed so nothing half-done ships. |
| [**fix-the-real-problem**](fix-the-real-problem) | Fix the cause, not the symptom, and reuse what others already solved. |
| [**reuse-ui-components**](reuse-ui-components) | Reuse your component library instead of building one-off screens. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill act-like-a-cto make-it-look-great change-code-safely fix-the-real-problem reuse-ui-components
```
