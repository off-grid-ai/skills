# Change code in small, safe, checked commits

![](overview.png)

Your agent follows the project's own rules, keeps changes additive, checks once in the background, and commits one change at a time with hooks on.

**Use it when**

- Your agent is about to edit code, run checks or commit.
- You want small commits that are easy to review and revert.
- You want no skipped hooks and no waiting on long builds.

**Try it:** "Fix the date bug in the reports page and commit it the safe way."
