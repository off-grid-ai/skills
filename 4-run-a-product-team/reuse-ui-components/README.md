# Build every UI change from your own component library

![](overview.png)

Your agent finds your design doc and component library, picks the best existing primitive for the job, and extends the library instead of adding one-off components.

**Use it when**

- Your agent adds or changes any UI.
- Your app has drifted into many slightly different buttons, cards or dialogs.
- You want proof that a change respects your design system.

**Try it:** "Add an empty state to the projects list using our shared components."
