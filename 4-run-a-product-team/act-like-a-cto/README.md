# Have your agent run your product like a careful CTO

![](overview.png)

Your agent learns how the project works, keeps all code changes in one thread, refuses to drop existing features, and loads the right skill for each kind of work.

**Use it when**

- You start real work on a product and want one set of standing rules.
- You run several agents and want only one of them changing code.
- You want every diff checked for lost behavior before it merges.

**Try it:** "Act as CTO on this repo and add offline support to the settings screen."
