# Build a game with agents

The same bar, set up for games in Godot, Unity, Unreal or the web.

| Skill | What you get |
| --- | --- |
| [**act-like-a-game-director**](act-like-a-game-director) | Your agent runs the game like a director: what's fun, what's urgent, what waits. |
| [**make-the-game-look-great**](make-the-game-look-great) | A look-and-feel bar for every screen, scene and animation. |
| [**finish-game-features**](finish-game-features) | Take a game feature all the way: built, seen working, pushed and shown. |
| [**playtest-every-scene**](playtest-every-scene) | Play through every scene and get a pass or fail with pictures. |
| [**prove-game-changes**](prove-game-changes) | Prove a change works with compile checks and renders. |
| [**start-your-game**](start-your-game) | Start every part of your game stack in the right order. |
| [**show-your-game-work**](show-your-game-work) | Push, document and show your game work. |
| [**talk-game-decisions**](talk-game-decisions) | Clear, short answers when you're making game decisions. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill act-like-a-game-director make-the-game-look-great finish-game-features playtest-every-scene prove-game-changes start-your-game show-your-game-work talk-game-decisions
```
