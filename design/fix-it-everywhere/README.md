# Turn a few screen notes into one rule applied to every screen
![](overview.png)

Leave notes on a few screens. Your agent works out the design rule behind them, writes it into your design docs once you agree, applies it to every screen, and shows you the result before and after.

## Use it when
- You left notes on a screen review page and want them acted on.
- You keep giving the same note on different screens.
- You want your design rules to grow from real feedback, not a style guide nobody reads.

Try it: "I've added comments on the screen review. Apply them everywhere."

Works on pages made by [show-me](../../review/show-me).
