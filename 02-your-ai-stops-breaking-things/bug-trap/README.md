# Tests that catch real bugs

![](overview.png)

A short checklist your agent follows every time it touches a test. You get tests that break when behaviour breaks, not when a button moves, and failures that get fixed at the cause.

Use it when:
- Your agent is about to write, change or fix a test.
- Tests keep breaking after harmless UI changes.
- Someone wants to "just raise the timeout" on a failing test.

Try it: "Add tests for the export feature, following bug-trap."
