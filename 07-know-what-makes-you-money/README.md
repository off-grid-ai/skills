# Know what makes you money

You have Stripe, analytics and store numbers and no idea what to change. Now you get the three moves that grow revenue most, and decisions you can make from one page.

![How know what makes you money works](how-it-works.png)

| Skill | What you get |
| --- | --- |
| [**grow-my-revenue**](grow-my-revenue) | Connect Stripe and your analytics. Get the three moves that grow revenue most. |
| [**help-me-decide**](help-me-decide) | Any big decision on one page: the answer first, every claim sourced, options scored. |
| [**weekly-wins**](weekly-wins) | What you shipped this week against last week, and what's next. |
| [**pick-the-best-ai-model**](pick-the-best-ai-model) | The best AI models for your app on every device, backed by public benchmarks. |
| [**mission-control**](mission-control) | One page of everything in flight across your projects, with what needs you on top. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill grow-my-revenue help-me-decide weekly-wins pick-the-best-ai-model mission-control
```

Claude Code: `/plugin marketplace add off-grid-ai/skills` then `/plugin install know-what-makes-you-money@off-grid-ai`.
Codex: `codex plugin marketplace add off-grid-ai/skills` then `codex plugin add know-what-makes-you-money@off-grid-ai`.
