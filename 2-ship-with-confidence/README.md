# Ship releases you trust


Proof that it works on real devices before anyone else sees it.

| Skill | What you get |
| --- | --- |
| [get-it-live](get-it-live) | Take a piece of work all the way to release-ready: built, tested, seen working. |
| [hand-test](hand-test) | Check a release on real phones and computers, with a clear bar for what a good test is. |
| [tests](tests) | Write tests that prove the whole user journey, not just one function. |
| [release-notes](release-notes) | Turn review comments into release notes your users actually read. |
| [oga-release](oga-release) | Release branch rules: what gets pushed where, with screenshots on every PR. |
| [oga-devices](oga-devices) | Run and drive your app on a Mac, an iPhone and an Android phone from the agent. |
| [oga-tests](oga-tests) | How tests get written and fixed so they catch real bugs. |
| [goc-get-it-live](goc-get-it-live) | The same "get it live" flow for a game: built, seen working, pushed and shown. |
| [goc-playtest](goc-playtest) | Play through a game scene by scene and get a pass or fail with pictures. |
| [goc-tests](goc-tests) | Prove a game change works with compile checks and renders. |
| [goc-run](goc-run) | Start every part of a game stack in the right order. |
| [goc-release](goc-release) | Push, document and show game work. |
