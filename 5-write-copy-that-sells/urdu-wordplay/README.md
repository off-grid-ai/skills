# Get original Hindi-Urdu lines built on wordplay

![](overview.png)

Give your agent a concept and it writes two or three short Hindi-Urdu pieces that sound like a friend talking, each built on a pair of sound-alike words that pull in opposite directions (tajnees). Every option names its pair, and nothing is copied from real songs.

Use it when:
- You want a caption, toast or card line in Hindi-Urdu with some craft to it.
- You like modern ghazal-pop lyrics and want something in that spirit on your own topic.
- You want to learn how tajnees works by seeing it applied.

Try it: "/urdu-wordplay leaving your city for a job"
