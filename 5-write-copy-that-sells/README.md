# Write copy that sells

Plain, specific words that get read and acted on, with no AI tells.

| Skill | What you get |
| --- | --- |
| [**write-like-a-human**](write-like-a-human) | Write like a real person: outcome first, short sentences, no AI tells. |
| [**copy-that-sells**](copy-that-sells) | Headlines, landing pages and emails that sell, on Bly and Ogilvy's rules. |
| [**write-as-a-founder**](write-as-a-founder) | Posts and outreach in your own voice, learned from what you've already written. |
| [**get-found-by-ai-search**](get-found-by-ai-search) | Articles that rank in search and get quoted in AI answers. |
| [**find-posts-worth-replying-to**](find-posts-worth-replying-to) | The posts worth your comment each day, with two angles for each. |
| [**urdu-wordplay**](urdu-wordplay) | Short Hindi-Urdu lines built on sound-alike word pairs. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill write-like-a-human copy-that-sells write-as-a-founder get-found-by-ai-search find-posts-worth-replying-to urdu-wordplay
```

Claude Code: `/plugin marketplace add off-grid-ai/skills` then `/plugin install write-copy-that-sells@off-grid-ai`.
Codex: `codex plugin marketplace add off-grid-ai/skills` then `codex plugin add write-copy-that-sells@off-grid-ai`.
