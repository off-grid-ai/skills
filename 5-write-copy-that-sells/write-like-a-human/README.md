# Get copy that sounds like a person wrote it

![](overview.png)

Your agent writes plain, direct, outcome-first copy and runs four checks on every draft: outcome first, three times "so what", what's in it for the reader, and cut until it hurts. Then it strips the AI tells.

Use it when:
- A draft reads like AI wrote it and you can't say why.
- You're writing a post, landing page, store listing, email or newsletter.
- Copy talks about the product instead of what the reader gets.

Try it: "/write-like-a-human Rewrite this launch post so a stranger would actually read it."
