# Make decisions faster

The answer first, every claim sourced, every option scored.

| Skill | What you get |
| --- | --- |
| [**one-page-decision-report**](one-page-decision-report) | A decision you can approve from one page, fact-checked by separate reviewers. |
| [**weekly-debrief**](weekly-debrief) | This week against last week: what worked, what didn't, what's next. |

```bash
npx skills add off-grid-ai/skills --skill one-page-decision-report weekly-debrief pick-the-right-ai-models
```
