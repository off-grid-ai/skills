# Plain words

Deciders ask for plain words when terms like "must-haves" and "weights" make no sense to them. Use the right-hand column in the report and in every question to the user.

| Don't write | Write |
|---|---|
| must-haves, deal-breakers, gates | must pass, rules an option out |
| weights, weighting | points (out of 100) |
| criteria | what matters |
| MECE | no overlap, nothing missing |
| BLUF, bottom line up front | the answer first |
| SCQ, SCQA, situation-complication | the problem, then the answer |
| governing thought | the main point |
| pre-mortem | imagine it failed, and say why |
| base rate, reference class, outside view | how similar cases went |
| tripwire | check-in date, or the number that triggers a review |
| RAPID, DACI, decision rights | who decides, who does it |
| stakeholders | the people affected (name them) |
| caveat | judgment, or "against" |
| confidence interval | range |
| leverage, synergy, alignment, unlock | say what actually happens |
| repo, SKILL.md, fork | name the thing and what it does |
| high/moderate confidence (unexplained) | how sure: high, because … |
| ICD 203, Kepner-Tregoe, coherence principle | sources table only |

Also: actors as subjects ("Sales fell 12%", not "There was a decline in sales"); short common words; sentences under about 20 words.
