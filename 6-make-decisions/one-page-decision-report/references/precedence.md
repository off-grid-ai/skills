# When rules or books disagree

Apply the first line that settles it.

1. **The decider's own words win.** If the decider asks for a format, a length or a word, use it.
2. **Tested beats studied beats practice.** A rule backed by experiments beats one from expert habit.
3. **The report is read alone, not presented.** So Tufte, Amazon and Duarte's Slidedocs win over sparse-slide advice (Reynolds, slide:ology): full sentences, dense detail behind clicks. If a slide version is also wanted, make it a second output.
4. **Bullets vs prose.** The first screen is one-line full statements (Smart Brevity, Minto). Everything under a line is short prose (Amazon, Tufte). Never nested bullet fragments.
5. **Answer first, always, for a decider.** Minto and Zelazny allow a delayed answer for a hostile reader; a decision report does not use that exception. Garner's condition still holds: give the question with the answer.
6. **Bold.** Rogers & Lasky-Fink (bold one thing) beats Smart Brevity (bold often).
7. **Confidence is not odds.** The source check (tyroneross) rates how well a claim is supported with words only: High, Medium, Low, Unverified. Never put a number on that. Odds are how likely an outcome is: always a number range (Tetlock). Both can appear; never mix them in one sentence (ICD 203).
8. **Group size.** Three to five per level (Minto caps at about five). Never pad to three.
9. **Simplify, but not for an expert.** Mayer's simplifying rules were tested on students; a decider knows their business. Cut extras, but don't explain basics they already know.
10. **Plain words beat book terms.** The book term goes in the sources table, the plain phrase goes in the text.
