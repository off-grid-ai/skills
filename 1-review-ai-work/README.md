# Review AI work in minutes, not days

Your agent writes code faster than you can read it. See only what changed, and make only the calls that need you.

| Skill | What you get |
| --- | --- |
| [**graph-engineering**](graph-engineering) | Change one thing and see every place it touches, then review the whole change on one page. |
| [**graph-engineering-loop**](graph-engineering-loop) | Make a few calls and it learns the rule behind them, applies it everywhere, and asks you less next time. |
| [**review-every-screen**](review-every-screen) | Every screen of your app on one page, with notes you pin on the exact spot. |
| [**apply-feedback-everywhere**](apply-feedback-everywhere) | Turn your notes on a few screens into one rule, applied to every screen. |
| [**get-prs-merge-ready**](get-prs-merge-ready) | Take a pull request to ready-to-merge, with every review comment answered. |
| [**check-code-before-merge**](check-code-before-merge) | A pass or fail on every change against one engineering standard. |
| [**learn-from-every-review**](learn-from-every-review) | Each review makes the standard sharper, so the same mistake doesn't come back. |
| [**test-every-page**](test-every-page) | Test a web app one page at a time and fix what breaks. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill graph-engineering graph-engineering-loop review-every-screen apply-feedback-everywhere get-prs-merge-ready check-code-before-merge learn-from-every-review test-every-page
```
