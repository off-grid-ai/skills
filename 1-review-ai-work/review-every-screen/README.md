# Review what your agent changed, one screen at a time
![](overview.png)

Every screen of your app on one page. Click a spot, write a note, and it is pinned there like a Figma comment. Your agent reads the notes, makes the changes, and shows each screen before and after with a reply under every note.

## Use it when
- You want to see every screen and state of your app in one place.
- You would rather point at a problem than describe it.
- Your agent changed the UI and you want before and after, side by side.
- You want the agent to mark what it thinks is wrong on the screen itself.

Try it: "Use review-every-screen to capture every screen of the web app so I can leave notes."

Works for web, iOS, Android, desktop and game projects. Without Claude Artifacts, the page runs locally and you export your notes to hand back.
