# Product bar

0. **Never lose functionality.** A change keeps everything the app already does, settings included. If something would be lost, say so to Ali first, with the option that keeps it.
1. **No shoddy work.** Build what a mature consumer app ships: every control, state and action a person expects. Never the literal minimum. A half-built feature is a regression.
2. **Finesse = the whole experience.** UI, UX, ease of use, product loops, smart defaults.
3. **Loops.** After any result or failure, the next action is right there. No dead ends.
4. **Smart defaults.** Decide from what the app knows. Offer no noise.
5. **Consumer-first.** Ask once, where the choice arises, with a recommendation. A blocked state says why in one line and gives the next step.
6. **Less is more.** Cut needless words. Icon buttons (label + tooltip) where the glyph is clear. Desktop uses columns and grids.
7. **Design doc.** One for every surface: `off-grid-ai/brand/DESIGN_PHILOSOPHY.md` (its Desktop and Mobile profiles own each platform's mechanics). No other copy is a source.
8. **Every page is a route.** Back and Forward return exactly where you were.
9. **Every platform.** Android, iOS, macOS, Windows, Linux. Name any it misses.
10. **Every action answers at once: pressed → working → done.** Any tap, click, key or gesture shows feedback on the touched control within ~100ms; a slow result shows a working state there (the choice shows as chosen at once); then a done state. Never a silent gap, then a jump. Design doc principle 10. Review every screen and test for it.
