# Plan a new project like a senior team would

Before any code, your agent researches the domain, then an architect, a product lead and a security lead each plan it on their own. You get one `PLAN.md` with phases you can ship, and the places they disagreed laid out for you to call.

Use it when:
- You're starting a new app, service or product.
- You want to know the stack, the phases and the risks before you build.
- You'd rather argue with a plan now than rewrite code later.

Try it: "/plan-from-scratch a booking app for physiotherapy clinics"
