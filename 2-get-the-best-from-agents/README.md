# Get the best out of every agent

Better answers and no lost work, in every session.

| Skill | What you get |
| --- | --- |
| [**push-back-with-facts**](push-back-with-facts) | Your agent argues back with facts instead of agreeing with you, and keeps your whole goal in view. |
| [**pick-up-any-chat**](pick-up-any-chat) | Pick up any past chat by its name and carry on where it stopped. Works across Claude Code accounts and Codex. |
| [**short-straight-answers**](short-straight-answers) | Short answers, result first, and it disagrees when it should. |
| [**run-agents-in-parallel**](run-agents-in-parallel) | Keep several agents building at once while one checks what landed. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill push-back-with-facts pick-up-any-chat short-straight-answers run-agents-in-parallel
```

Claude Code: `/plugin marketplace add off-grid-ai/skills` then `/plugin install get-the-best-from-agents@off-grid-ai`.
Codex: `codex plugin marketplace add off-grid-ai/skills` then `codex plugin add get-the-best-from-agents@off-grid-ai`.
