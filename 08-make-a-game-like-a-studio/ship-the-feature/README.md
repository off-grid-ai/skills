# Finish your game features, all the way to done

![](overview.png)

Your agent works out what is left, builds each piece, proves it on screen, commits and pushes it, and shows you screenshots. You get a short status: done, in progress, left, and what needs your hands.

Use it when:
- You have a list of half-done game features and want them finished.
- You want every change seen working, not just compiled.
- You want screenshots of each new scene as it lands.

Try it: "Finish the inventory screen and the save menu, and show me each one working."
