# Make a game like a studio would

Making a game alone with AI? Now it has a director, an art director and a QA team that playtests every scene.

![How make a game like a studio would works](how-it-works.png)

| Skill | What you get |
| --- | --- |
| [**game-director**](game-director) | Your AI runs the game like a director: what's fun, what's urgent, what waits. |
| [**art-director**](art-director) | Every screen, scene and animation held to one look. |
| [**playtest**](playtest) | It plays through every scene and hands you a pass or fail with pictures. |
| [**ship-the-feature**](ship-the-feature) | Any game feature taken all the way: built, seen working, pushed, shown. |
| [**prove-it**](prove-it) | Proof a change works, with compile checks and renders. |
| [**boot-game**](boot-game) | Your whole game stack started in the right order, every time. |
| [**devlog**](devlog) | Push, document and show off your progress. |
| [**game-calls**](game-calls) | Straight answers when you're making game decisions. |

## Install just this set

```bash
npx skills add off-grid-ai/skills --skill game-director art-director playtest ship-the-feature prove-it boot-game devlog game-calls
```
